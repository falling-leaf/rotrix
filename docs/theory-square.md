# Rotrix 理论分析报告：正方形拓扑的数学建模与求解

> 日期：2026-08-01
> 范围：4×4 与 6×6 正方形拓扑（仅顺时针旋转操作）
> 分析工具：SymPy 置换群计算 + 双向 BFS 实验验证

---

## 1. 玩法的形式化建模

### 1.1 棋盘与状态空间

**4×4 棋盘**：16 个格子的线性排列（行优先索引 0..15），4 种颜色各 4 块。

**6×6 棋盘**：36 个格子的线性排列（行优先索引 0..35），4 种颜色各 9 块。

目标棋盘是四个象限分别纯色的固定排列。以 4×4 为例：

```
R R | Y Y
R R | Y Y     R=红  Y=黄
----+----     目标 = [R,R,Y,Y, R,R,Y,Y, B,B,G,G, B,B,G,G]
B B | G G     B=蓝  G=绿
B B | G G
```

### 1.2 旋钮与操作

**4×4**：9 个旋钮（3×3 排布），每个旋钮旋转其覆盖的 2×2 区域的 4 个色块。
旋钮 K(r,c) 的 cells = [TL, TR, BR, BL]（顺时针序），r,c ∈ {0,1,2}。

**6×6**：25 个旋钮（5×5 排布），结构同上。

**顺时针旋转（CW）的语义**：

```
new[i] = old[(i + 3) % 4]
```

即 [BL, TL, TR, BR] ← [TL, TR, BR, BL]。从置换角度看，CW 将位置 cells[j] 的色块移到 cells[(j+1)%4]，这是一个 4-循环 (cells[0] → cells[1] → cells[2] → cells[3] → cells[0])。

关键性质：CW⁴ = 恒等（周期为 4），CW³ = CCW（逆时针），CW² = 对角对换。

### 1.3 置换群模型

将棋盘的每种颜色排列视为一个**置换**（对 16 个标号位置的排列），旋钮操作群 G 定义为：

```
G = ⟨ CW(K₀₀), CW(K₀₁), ..., CW(K₂₂) ⟩  （4×4，9 个生成元）
G = ⟨ CW(K₀₀), CW(K₀₁), ..., CW(K₄₄) ⟩  （6×6，25 个生成元）
```

每个生成元是一个 4-循环，是**奇置换**（长度为 4 的循环符号为 (-1)³ = -1）。

## 2. 问题一：任意打乱地图的可解性

### 2.1 两个层面的不变量

旋转操作有两个层面的不变量：

**不变量 1（颜色分布不变量）**：旋转操作只是移动色块，不改变任何颜色的计数。
- 4×4 目标棋盘：红=4、黄=4、蓝=4、绿=4
- 6×6 目标棋盘：红=9、黄=9、蓝=9、绿=9

任何颜色计数不匹配的"打乱"棋盘（例如全红、或红色变成 5 块）**必然无解**。

**不变量 2（置换奇偶性？）**：需要检查群 G 是否包含奇置换。若 G ⊆ Aₙ（交错群），则置换奇偶性是额外不变量。

### 2.2 群结构计算结果（SymPy 验证）

使用 SymPy 的 `PermutationGroup` 构造群并计算：

| 拓扑 | 旋钮数 | 棋盘格数 | 群阶 |G| | 是否 = Sₙ | 是否 = Aₙ | 可解群 |
|------|--------|----------|------------|-----------|-----------|--------|
| 4×4  | 9      | 16       | 20,922,789,888,000 (= 16!) | **是** | 否 | 否 |
| 6×6  | 25     | 36       | 3.72×10⁴¹ (= 36!) | **是** | 否 | 否 |

**核心结论**：

1. **G = S₁₆（4×4）和 G = S₃₆（6×6）**——旋钮群等于完全对称群。
2. 群是**传递的**（transitive）——只有 1 个轨道，所有 16/36 个位置互相可达。
3. 群包含奇置换（每个 CW 生成元都是奇置换）——G 不包含于 Aₙ。
4. 因此**不存在置换奇偶性不变量**——任何置换都在群中。

### 2.3 "仅 CW 操作"是否改变群结构？

不改变。因为 CW³ = CCW，群 ⟨CW₁, CW₂, ...⟩ 自动包含每个旋钮的 CCW 操作。所以仅允许 CW 的群 = 允许 CW+CCW 的群 = Sₙ。

### 2.4 可解性判定定理

**定理（可解性充要条件）**：

一个打乱棋盘 B 有解（存在有限次 CW 旋转序列将其还原到目标棋盘 T），当且仅当：

> **B 与 T 的颜色分布完全相同**（每种颜色的块数一致）。

**证明**：

(⟹) 旋转操作是置换，不改变颜色计数。所以 B 有解 ⟹ B 与 T 颜色分布相同。

(⟦) 设 B 与 T 颜色分布相同。将 B 和 T 的色块编号（同色块任意标号），得到两个排列 σ_B, σ_T ∈ Sₙ。它们的差 σ = σ_T ∘ σ_B⁻¹ ∈ Sₙ。因为 G = Sₙ，σ ∈ G，所以存在有限次旋钮 CW 操作实现 σ，将 B 还原到 T。

更精确地说：颜色分布相同意味着 σ 是"保持颜色类的置换"，即 σ ∈ S₄ ≀ S₄（4×4）或 S₉ ≀ S₉（6×6）的 Young 子群。因为 G = Sₙ ⊇ 该子群，所以 σ ∈ G。

**推论**：

- 4×4：共有 16!/(4!)⁴ = 63,063,000 种不同的颜色排列，其中全部有解（颜色分布均匹配目标）。
- 6×6：共有 36!/(9!)⁴ ≈ 2.15×10¹⁹ 种颜色排列，全部有解。
- "任意打乱"如果意味着**色块随机分布**（颜色数量可能不匹配），则**不保证有解**——仅当颜色数量恰好匹配目标时才有解。

## 3. 问题二：最优解的快速求解

### 3.1 最优解的定义

给定有解棋盘 B 和目标棋盘 T，最优解 = 使 CW 操作次数最少的操作序列。

### 3.2 CW-only 操作的求解特点

由于仅有 CW 操作（无 CCW），逆操作 = CW³（3 次 CW）。这导致：

- 打乱 1 步（CW_k）→ 还原需要 CW_k³ = 3 步
- 打乱 N 步（不同旋钮）→ 上界 3N 步，但可能更少（旋钮重叠优化）

### 3.3 实验数据（双向 BFS 求解）

| 打乱步数 | 最优解步数 | 比值(最优/打乱) | 上界 3N | 求解耗时 |
|---------|-----------|----------------|---------|---------|
| 3       | 9         | 3.00           | 9       | 0.07s   |
| 5       | 15        | 3.00           | 15      | 27.04s  |
| 8       | 16        | 2.00           | 24      | 172.17s |

观察：
- scramble=3,5 时最优解恰好 = 3×scramble（每个逆操作都需 CW³，无优化空间）
- scramble=8 时最优解 = 16 < 24（旋钮重叠使得部分操作可合并，比值降至 2.0）

### 3.4 求解算法复杂度分析

#### 3.4.1 精确最优解 — BFS / 双向 BFS

**单向 BFS**：从 B 出发逐层搜索，直到遇到 T。
- 时间复杂度：O(b^d)，b ≈ 6.7（有效分支因子），d = 最优解深度
- 空间复杂度：O(b^d)
- 4×4 的 d 可达 9-16+，b^d 在 10⁶-10¹³量级，**对深打乱不可行**

**双向 BFS**：从 B 和 T 同时搜索，在中间相遇。
- 时间复杂度：O(b^(d/2))
- 空间复杂度：O(b^(d/2))
- 4×4 的 d=15 时需 b^7.5 ≈ 10⁶ 级状态，Python 约 30 秒
- d=16 时需 b^8 ≈ 10⁷ 级，Python 约 3 分钟
- **对 d ≤ 16 可行，更深的打乱需要优化**

#### 3.4.2 IDA*（迭代加深 A*）

使用启发式函数（如错位色块数、曼哈顿距离和）进行剪枝。
- 时间复杂度：O(b^d)（但有效分支因子大幅降低）
- 空间复杂度：O(d)
- 适合大规模搜索，但需要设计好的启发式

#### 3.4.3 启发式函数设计

可行的启发式：
1. **错位色块数**：不在目标象限的色块数，h₁ = |{i : color(i) ≠ target_color(i)}| / 4
2. **最小旋转数下界**：每个错位色块至少需要 1 次 CW 移动，h₂ = max over wrong cells of min_rotations
3. **模式数据库（Pattern Database）**：预计算子问题的精确最优解，作为启发式

#### 3.4.4 渐近最优深度估计

4×4 有效分支因子 b ≈ 6.7，总排列数 16! ≈ 2.09×10¹³：
- 覆盖整个 S₁₆ 需要深度 d ≈ log(16!)/log(6.7) ≈ 44.3/2.74 ≈ 16.2
- 即**最坏情况最优解深度约 16-17 步 CW 旋转**

6×6 有效分支因子 b ≈ 20+，总排列数 36! ≈ 3.72×10⁴¹：
- 覆盖整个 S₃₆ 需要深度 d ≈ log(36!)/log(20) ≈ 96/4.3 ≈ 22.3
- 即**最坏情况最优解深度约 22-23 步 CW 旋转**

### 3.5 实用求解策略推荐

| 打乱规模 | 推荐算法 | 预期耗时 |
|---------|---------|---------|
| 轻度(scramble ≤ 5) | 双向 BFS | < 30s |
| 中度(scramble 5-10) | IDA* + 错位启发式 | < 1min |
| 重度(scramble 10-20) | IDA* + Pattern Database | < 5min |
| 极重(scramble 20+) | 启发式近似解（非最优） | 实时 |

## 4. 总结

### 4.1 可解性

| 条件 | 可解性 |
|------|--------|
| 颜色分布匹配目标（每种颜色块数正确） | **有解**（G = Sₙ，所有同分布排列可达） |
| 颜色分布不匹配（某种颜色块数错误） | **无解**（颜色计数不变量） |

4×4 有 63,063,000 种有解颜色排列；6×6 有 ~2.15×10¹⁹ 种。"任意打乱"若包含颜色数量不匹配的情况，则不保证有解。

### 4.2 最优解

- **精确算法**：双向 BFS 可在合理时间内求解深度 ≤ 16 的 4×4 棋盘（最优解 ≤ 16 步 CW）
- **复杂度**：O(b^(d/2))，4×4 的 b ≈ 6.7，最坏 d ≈ 16-17
- **上界**：最优解 ≤ 3 × 打乱步数（因为 CW³ = CCW），但旋钮重叠时可更优
- **实用推荐**：轻度用双向 BFS，中重度用 IDA* + 启发式，极重用近似算法

### 4.3 仅 CW 操作的影响

仅 CW 不改变群结构（G 仍 = Sₙ，因为 CW³ = CCW），但使最优解步数膨胀——每个"逻辑逆操作"需要 3 步 CW。这使得最优解深度约为 CW+CCW 双向操作的 1.5-3 倍。
