# Rotrix 难度分析：6×6 常规（square-6x6-regular）

> 拓扑：`square-6x6`　旋钮数：25　格子数：36
> Goal 类型：`quadrant-uniform`　拓扑混合时间 τ ≈ 49.8 步

## 1. 统一难度公式

```
DC(N) = H∞ · (1 − e^(−N/τ))
  H∞ = 1 − Σ p_t²   （稳态错位率）
  τ  = 混合时间常数  （拓扑属性）
  N  = 打乱步数
```

## 6. 结论

- 拓扑混合时间 τ≈49.8 步（旋钮网络固有），是打乱"充分度"的时间标尺。
- 1τ(50步)≈63%、2τ(100步)≈86%、3τ(149步)≈95% 收敛；超过 3τ 再加打乱收益甚微。
- 本玩法各关卡 DC(N)=H∞·(1−e^(−N/τ)) 与 ABS=DC·S 见第 2 节表。
