# Rotrix 难度分析：N3 三角形常规（hex-n3-regular）

> 拓扑：`hex-triangle`　旋钮数：19　格子数：54
> Goal 类型：`hex-uniform`　拓扑混合时间 τ ≈ 41.1 步

## 1. 统一难度公式

```
DC(N) = H∞ · (1 − e^(−N/τ))
  H∞ = 1 − Σ p_t²   （稳态错位率）
  τ  = 混合时间常数  （拓扑属性）
  N  = 打乱步数
```

## 6. 结论

- 拓扑混合时间 τ≈41.1 步（旋钮网络固有），是打乱"充分度"的时间标尺。
- 1τ(41步)≈63%、2τ(82步)≈86%、3τ(123步)≈95% 收敛；超过 3τ 再加打乱收益甚微。
- 本玩法各关卡 DC(N)=H∞·(1−e^(−N/τ)) 与 ABS=DC·S 见第 2 节表。
