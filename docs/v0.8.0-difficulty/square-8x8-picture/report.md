# Rotrix 难度分析：8×8 拼图（square-8x8-picture）

> 拓扑：`square-8x8`　旋钮数：49　格子数：64
> Goal 类型：`picture`　拓扑混合时间 τ ≈ 121.2 步

## 1. 统一难度公式

```
DC(N) = H∞ · (1 − e^(−N/τ))
  H∞ = 1 − Σ p_t²   （稳态错位率）
  τ  = 混合时间常数  （拓扑属性）
  N  = 打乱步数
```

## 5. 三因素分析：打乱步数 / 色块种类数 / 布局

带图标与拼图玩法原理相同（逐格精确还原）。难度由三个因素决定：

1. **打乱步数 N**：决定混合因子 `1−e^(−N/τ)`，落在 0~1（τ 为拓扑混合时间）。
2. **色块种类数 K**：`H∞ = 1 − Σp_t²` 随 K 增大而升高；K 越大，颜色/图标的交叉越细，
   每次旋转错位的"精确类型"越多，错位率上升越快（实测 τ_eff 越小）。
3. **地图布局**：决定各类型占比 `p_t`（直接决定 H∞）与纹理复杂度 E（每个旋钮覆盖区的信息熵均值）。

- 第31关：K=5，H∞=0.6582，S=106.7，E=0.282
- 第32关：K=4，H∞=0.6831，S=106.0，E=0.316
- 第33关：K=4，H∞=0.6348，S=96.0，E=0.331
- 第34关：K=4，H∞=0.6855，S=106.6，E=0.412
- 第35关：K=4，H∞=0.3892，S=63.4，E=0.215

## 6. 结论

- 拓扑混合时间 τ≈121.2 步（旋钮网络固有），是打乱"充分度"的时间标尺。
- 1τ(121步)≈63%、2τ(242步)≈86%、3τ(364步)≈95% 收敛；超过 3τ 再加打乱收益甚微。
- 本玩法各关卡 DC(N)=H∞·(1−e^(−N/τ)) 与 ABS=DC·S 见第 2 节表。
