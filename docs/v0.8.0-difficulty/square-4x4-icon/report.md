# Rotrix 难度分析：4×4 带图标（square-4x4-icon）

> 拓扑：`square-4x4`　旋钮数：9　格子数：16
> Goal 类型：`icon`　拓扑混合时间 τ ≈ 9.8 步

## 1. 统一难度公式

```
DC(N) = H∞ · (1 − e^(−N/τ))
  H∞ = 1 − Σ p_t²   （稳态错位率）
  τ  = 混合时间常数  （拓扑属性）
  N  = 打乱步数
```

## 5. 三因素分析：打乱步数 / 色块种类数 / 布局

带图标与拼图玩法原理相同（逐格精确还原）。难度由三个因素决定：

1. **打乱步数 N**：决定混合因子 `1−e^(−N/τ)`，落在 0~1（τ 为拓扑混合时间）。
2. **色块种类数 K**：`H∞ = 1 − Σp_t²` 随 K 增大而升高；K 越大，颜色/图标的交叉越细，
   每次旋转错位的"精确类型"越多，错位率上升越快（实测 τ_eff 越小）。
3. **地图布局**：决定各类型占比 `p_t`（直接决定 H∞）与纹理复杂度 E（每个旋钮覆盖区的信息熵均值）。

- 第6关：K=6，H∞=0.7969，S=29.9，E=0.423
- 第7关：K=8，H∞=0.8438，S=33.9，E=0.736
- 第8关：K=8，H∞=0.8750，S=36.3，E=0.778
- 第9关：K=8，H∞=0.8750，S=36.3，E=0.667
- 第10关：K=8，H∞=0.8438，S=33.9，E=0.514

## 6. 结论

- 拓扑混合时间 τ≈9.8 步（旋钮网络固有），是打乱"充分度"的时间标尺。
- 1τ(10步)≈63%、2τ(20步)≈86%、3τ(30步)≈95% 收敛；超过 3τ 再加打乱收益甚微。
- 本玩法各关卡 DC(N)=H∞·(1−e^(−N/τ)) 与 ABS=DC·S 见第 2 节表。
