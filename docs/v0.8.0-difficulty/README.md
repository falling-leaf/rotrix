# Rotrix v0.8.0 难度分析总览

> 9 种玩法的统一难度量化。每个玩法详见对应子目录 `report.md`。

## 统一难度公式

```
DC(N) = H∞ · (1 − e^(−N/τ))
  H∞ = 1 − Σ p_t²   稳态错位率（由精确类型分布决定）
  τ  = 混合时间常数（由拓扑旋钮网络决定）
  N  = 打乱步数
  ABS(绝对难度) = DC(N) · log₂(C)，C = N!/∏n_t!（状态空间）
```

## 核心结论

1. **统一公式成立**：9 种玩法难度均可由 `DC(N)=H∞(1−e^(−N/τ))` 描述。

2. **τ 是拓扑属性**，只取决于旋钮网络（5 种拓扑 5 个 τ），与目标态、玩法无关。

3. **H∞ 是玩法内容属性**，由精确类型分布决定：颜色数/图标/点数/布局的颜色占比。

4. **icon/拼图原理相同**：逐格精确还原，难度 = 打乱步数（τ 内） × 色块种类数（→H∞） × 布局（→p_t 与纹理 E）。

5. **骰子 4×4** 精确类型数最高（K=16），稳态错位率 H∞=0.9375 为所有玩法之最。
